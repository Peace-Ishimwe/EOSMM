# Ebola Outbreak Social Media Monitor (EOSMM)

**Last updated: May 23, 2026**

## What this is
An interactive dashboard tracking what people are saying about the 2026 Ebola (Bundibugyo strain) outbreak on social media and news across Rwanda and neighboring countries (DRC, Uganda, Burundi, Tanzania, Kenya, South Sudan).

## How to use it
Open `index.html` in any web browser — no internet connection required.

## Tabs
- **Overview** — Key stats, alert level, outbreak summary
- **Social Media** — Platform-by-platform sentiment breakdown
- **Misinformation** — Active false narratives with fact-check links
- **Geography & Risk** — Country/district risk table + Rwanda district breakdown
- **Timeline** — Chronological outbreak events with source links
- **Monitoring Guide** — How to monitor social media manually
- **Geo Map** — Interactive map of 33 cities, hover bubbles for detail

## Coverage
- 33 cities across 7 countries on the geo map
- 9 Rwanda districts with individual risk profiles
- All source links verified and clickable throughout
- Sources: WHO, Africa CDC, ECDC, BBC, Reuters, Al Jazeera, CNN, France 24, The East African, New Times Rwanda, Rwanda MoH

## Data as of May 23, 2026
- ~160 deaths | 650+ suspected cases | 64 confirmed (DRC)
- Rwanda: borders with DRC fully closed (5 named crossing points)
- WHO PHEIC declared | Africa CDC PHECS declared
